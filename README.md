# ML_task_05

В ходе практической работы была обучена модель бинарной классификации на основе логистической регрессии. Для оценки качества использовались вероятности классов, ROC-кривая, PR-кривая, ROC-AUC, Average Precision, а также метрики Accuracy, Precision, Recall и F1.

Для подбора порога учитывалась различная стоимость ложноположительных и ложноотрицательных ошибок. Порог выбирался на валидационной выборке по минимальной суммарной стоимости ошибок, после чего оба варианта сравнивались на отдельной тестовой выборке.

При пороге 0,5 суммарная стоимость ошибок составила 474, а при подобранном пороге — 428. Значения Precision, Recall и F1 изменились соответственно с 0.600 на 0.211, с 0.06 на 0.57 и с 0.109 на 0.308.

Таким образом, выбор порога должен учитывать не только общую точность классификации, но и последствия каждого типа ошибки. Предпочтительным является вариант с меньшей стоимостью ошибок, если полученное изменение метрик соответствует требованиям задачи.
